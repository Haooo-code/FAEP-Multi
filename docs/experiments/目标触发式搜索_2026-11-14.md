# 目标触发式搜索实验

日期：2026-11-14

## 1. 目标

当前 FAEP-Multi 在“没有前沿”时结束。目标搜索版本把任务目标改为：

- 未发现目标：继续按目标先验搜索未知区域。
- 检测到候选目标：先执行多帧或第二架飞机复核。
- 确认目标：立即停止所有飞机的前沿扩展，并在当前位置悬停观察。
- 目标不存在：完成全图兜底搜索后报告 `NOT_FOUND`。

## 2. 实现结构

### 2.1 目标先验

`FastExplorationManager` 新增以下参数：

| 参数 | 含义 |
|---|---|
| `exploration/target_search_enabled` | 是否启用目标触发式探索 |
| `exploration/target_prior_x/y/z` | 已知的大致目标区域中心 |
| `exploration/target_prior_radius` | 初始优先搜索半径 |
| `exploration/target_prior_growth` | 半径随时间扩大的速度，m/s |
| `exploration/target_prior_max_radius` | 最大优先半径 |

候选前沿按原有航程、可执行性和扇区约束过滤后，若目标先验半径内存在前沿，则优先选择这些前沿；如果半径内没有前沿，自动回退到全局前沿。该策略不会因为先验错误而永久卡死。

### 2.2 模拟目标感知

`target_search/target_perception_sim.cpp` 使用共享真值地图外的隐藏目标位置模拟一次检测过程。规划器不能读取该真值，只接收带噪声的检测结果。

检测条件：

- 目标投影进入相机视场；
- 距离在最小、最大量程之间；
- 投影像素处的深度没有显示前方遮挡；
- 按距离、视场边缘和随机漏检概率采样检测是否成功；
- 输出带噪声的位置和置信度。

消息接口：

- `/target/detection`：`coord_msgs/TargetDetection`
- `/target/status`：`coord_msgs/TargetStatus`
- `/target/marker`：RViz 候选/确认目标标记

### 2.3 分级确认

协调器维护每架飞机 10 秒内的检测证据：

- 单架飞机在 2.5 秒内连续 3 帧达到高置信度，直接确认。
- 低置信度需要至少两架飞机各自的连续检测证据。
- 候选证据超过 10 秒未完成复核，回到 `SEARCHING`，继续前沿探索。

### 2.4 全局停止

确认后协调器发布 `/coord/halt`。探索管理器进入 `FINISH`，清除前沿规划，并持续发布当前安全位置的悬停位置指令。目标不存在时在正常探索收束后广播 `NOT_FOUND`。

## 3. 验证结果

### 3.1 目标存在

场景：office2，目标位于 `(1.0, 3.0, 1.0)`，先验中心与目标区域相同，最大感知距离 8 m。

| 轮次 | 实际耗时 s | 结果 |
|---|---:|---|
| 1 | 25 | D3 多帧确认，三机停止探索 |
| 2 | 21 | D3 多帧确认，三机停止探索 |
| 3 | 22 | D3 多帧确认，三机停止探索 |

三轮均成功，目标发现后的探索停止正常。此表只统计触发到确认停止的时间；发现时的并集覆盖仍需补算，不能据此宣称覆盖一定降低。
原始汇总表见 `data/target_search_results_20261114.csv`。

### 3.2 目标不存在

场景：office2，`target_present=false`，目标先验半径快速增长到最大 8 m，模拟先验错误后转入全图兜底。

结果：

- 全程没有目标。
- 没有误报或提前停止。
- 系统继续探索到正常任务收束，wall 为 87 s。

关闭目标搜索的三机分区回归轮 wall 为 82 s，未启动任何目标感知节点，原有协同探索仍能正常完成。

### 3.3 需要保留的限制

- 目标感知是模拟器，不代表真实视觉人物检测。
- 本轮多机确认主要依赖单机连续高置信检测；低置信度双机复核逻辑已实现，但还需要更多目标位置和置信度参数实验。
- 目标为静态目标，尚未覆盖移动目标、动态遮挡和真实相机噪声。
- 目标先验半径增长速度会影响无目标场景的总时长，需要在演示场景中单独调参。

## 4. 复现入口

```bash
roslaunch exploration_manager multi_bringup.launch \
  use_coord:=true partition_mode:=true \
  map_file:=$(rospack find map_generator)/resource/office2.pcd \
  map_size_x:=42 map_size_y:=42 map_size_z:=10.0 \
  box_x_min:=-10.4 box_y_min:=-9.9 box_z_min:=-0.1 \
  box_x_max:=10.4 box_y_max:=9.9 box_z_max:=2.0 \
  d1_x:=-7.5 d1_y:=-3.5 d1_z:=1.0 \
  d2_x:=4.5 d2_y:=-3.5 d2_z:=1.4 \
  d3_x:=-3.5 d3_y:=6.5 d3_z:=1.8 \
  target_search_enabled:=true \
  target_x:=1.0 target_y:=3.0 target_z:=1.0 \
  target_prior_x:=1.0 target_prior_y:=3.0 target_prior_z:=1.0 \
  target_prior_radius:=3.0 target_prior_growth:=0.05 \
  target_prior_max_radius:=8.0 target_sensor_max_range:=8.0
```
