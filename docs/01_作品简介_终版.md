# 作品简介

FAEP-Multi 将开源单机 FAEP 扩展为三机协同探索系统。单机探索速度有限，三机直接并行会重复覆盖。每架机保留建图、前沿检测、轨迹规划与飞控，协调器负责任务分配和统一终止。系统按初始位置划分 Voronoi 扇区，任务创建即归属扇区机，单机只处理本扇区前沿。团队修复了搜索树父指针成环导致的 OOM，节点内存稳定在约 1.54 GB。三场景对照中，相对三机独立，单机时间低 43.8% 到 50.0%，总时长低 45.1% 到 56.0%，重复覆盖降至 0 到 19%。未分区的 v1 反而慢 21.1% 到 29.3%。代码、数据和复现工具已开源。
