# 作品简介

FAEP-Multi 将开源单机自主探索算法 FAEP 扩展为三机协同系统。每架机保留完整建图、前沿检测、轨迹规划和飞控逻辑，协调器只负责任务层。系统按各机初始位置划分一维 Voronoi 扇区，任务创建即归属扇区机，单机只在本扇区选择与上报前沿，完成后统一 HALT。团队还定位并修复上游搜索树父指针成环导致的 OOM，使探索节点内存稳定在约 1.54 GB。三场景 A/B/C 对照中，协同版相对三机独立，单机时间低 43.8% 到 50.0%，wall 低 45.1% 到 56.0%，重复覆盖从 89% 到 98% 降至 0 到 19%；未分区 v1 比独立慢 21.1% 到 29.3%，为空间分工提供了对照证据。FAEP 衍生部分以 GPL-3.0 开源，数据和复现工具随仓库提供。
